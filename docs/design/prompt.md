Generated with the built-in image generation tool for the Private Skills registry. The saved reference is `ui-concept.png`; the application implements real React interfaces from the direction rather than rendering the concept as a screenshot.

## Reusable design prompt

Create a polished desktop product UI concept board for “Private Skills”, a private AI agent skill registry. Use warm ivory surfaces, deep ink typography, sage green navigation and primary controls, subtle lavender for Eve intelligence panels, and generous whitespace. Use an editorial serif for major headings with a precise readable sans-serif for controls. Show three connected flows: a Discover catalog with semantic search and skill cards; a skill detail with provenance, security scan badges and a copyable install command; and an Eve consolidation review comparing related skills with evidence and explicit accept or dismiss controls. Include a compact persistent sidebar, restrained install analytics, clear empty/loading/error states, and an accessible responsive hierarchy. Keep the visual calm, sophisticated, and practical, with no decorative dashboard clutter. All displayed names and metrics in the concept are illustrative; the implementation must use live API data.

## Implemented intent

- Discover and catalog use the registry's actual permissions, releases and scan status.
- Analytics distinguish client-confirmed installs from artifact downloads.
- Eve proposes consolidation; accepting a proposal records a decision and never automatically merges skill artifacts.
- Semantic search uses real configurable embeddings with current authorization and policy checks.
